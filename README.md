# Learning Next.js

A small Next.js App Router starter project. The current home page is the default create-next-app screen; this repository is a place to practice and build on that starter.

## Run locally

Requires Node.js and npm.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. The home page is in `src/app/page.tsx`.

Available scripts are `npm run dev`, `npm run build`, `npm start`, and `npm run lint`.
